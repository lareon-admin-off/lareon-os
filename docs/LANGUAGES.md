# Languages (17)
English (en), Spanish (es), French (fr), German (de), Portuguese (pt), Italian (it), Russian (ru), Turkish (tr), Swedish (sv), Japanese (ja), Korean (ko), Mandarin Chinese (zh), Hindi (hi), Arabic (ar), Farsi (fa), Swahili (sw), Moroccan Arabic / Darija (ary).
Arabic, Farsi and Darija read right to left. Each language has a flag, and Darija uses the Algerian flag (my choice). No regional variants.
Translations for Lareon's own screens already exist in the Lareon desktop app (`src/i18n.js` and `src/i18n-more.js` in the lareon-desktop repo) and can be reused for the installer.
