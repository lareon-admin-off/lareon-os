# Lareon OS assets
Everything the Lareon OS project needs from the Lareon side.

- `brand-kit/` has the real logos (SVG and PNG), colors, and the Geist and Geist Mono fonts (free, SIL OFL license included). Use these exactly; do not redraw anything. Put the logos in `artwork/brand/` in the lareon-os repo and the fonts where the build installs system fonts.
- `wallpaper-kit/` has the real Lareon mountain scene, the four time-of-day palettes and 4K renders. Already used by the OS build; here for reference.
- `LANGUAGES.md` has the 17 languages for the installer and first-boot setup.

Lareon is a Larsonia-based, nation-owned company; products: Fledge (email), Aster (AI assistant), Dusk (calendar, tasks, notes), Ember (browser), and the Lareon desktop app. One free Lareon account for all of them.
